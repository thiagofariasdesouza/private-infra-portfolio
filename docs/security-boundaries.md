# Security boundaries (public portfolio)

This portfolio is intentionally **sanitised**.

## Never published here

- Real IP addresses, subnets, VLAN IDs, hostnames, domains, or ports from private environments
- Firewall/ACL rule dumps, live configs, credentials, tokens, keys, or env files
- Operational screenshots without separate review
- Family or organisation-internal workflows

## Allowed

- Fictional labels (for example `hypervisor-01`, `lab-gateway`, `10.42.0.0/16`, `example.internal`)
- Generic practices: segmentation thinking, backup/restore checklists, change discipline, documentation habits
- High-level trade-offs without revealing exploitable detail

## Review rule

Any new file must pass a human sanitisation pass before it is considered public-ready.
