# Lessons learned (sanitised)

1. **Study lab is not an operable platform** until segmentation, access control, recovery and docs catch up.
2. **Restore beats backup green checks** for confidence.
3. **Phased edge changes** cost more planning time and save incident time.
4. **Hybrid** is a product decision (privacy vs always-on), not only a tech preference.
5. **Human review gates** keep automation and agents useful without over-claiming autonomy.
