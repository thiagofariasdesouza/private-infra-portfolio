# Operational practices (generic)

Practices worth keeping in a small private infrastructure environment:

- Inventory and documentation stay close to reality (even if the public version is fictionalised).
- Backup is incomplete without a **restore test** in an isolated path.
- Edge/connectivity changes prefer **staged cutovers** over big-bang swaps.
- Automation reduces toil; **approval gates** protect production-like impact.
- AI-assisted drafting is welcome; unsupervised production agents are out of scope for claims here.
